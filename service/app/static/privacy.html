01

Назначение сервиса

Сервис предназначен для автоматического обнаружения объектов антропогенного загрязнения городской среды на изображениях с использованием нейронной сети. Сервис доступен через веб-интерфейс на сайте rubbish-detector.ru, а также через VK-бота для управляющих компаний и сотрудников по уборке территорий.

02

Какие данные обрабатываются

Веб-интерфейс. Пользователь может загрузить изображение для анализа. Загруженное изображение используется только для поиска объектов загрязнения и формирования результата. Персональные данные не собираются. В технических журналах сервера фиксируется IP-адрес запроса; журналы используются для обеспечения работы и безопасности сервиса и хранятся не более 30 дней.

VK-бот. При регистрации и использовании бота обрабатываются:

  • VK-идентификатор и имя профиля пользователя;
  • контактный телефон — при регистрации представителя управляющей компании;
  • фотографии убранных территорий и текстовые комментарии — при отправке отчётов сотрудниками (лица людей и автомобильные номера на фотографиях необратимо обезличиваются до сохранения).

Хранение данных

Веб-интерфейс. Загруженные изображения обрабатываются в момент запроса и не сохраняются. Они могут временно находиться в памяти сервера только на период обработки.

VK-бот. Фотографии, отправленные сотрудниками через бота, сохраняются в защищённом облачном хранилище на территории Российской Федерации. Хранятся оригинальная версия фото и версия с разметкой результатов детекции. Срок хранения — 3 года с момента получения, затем данные удаляются. Персональные данные могут быть удалены досрочно по отзыву согласия субъекта.

04

Использование данных для обучения модели

Фотографии территорий, отправленные сотрудниками через VK-бота, могут использоваться для дообучения и улучшения модели распознавания мусора.

Для обучения используются только обезличенные копии фотографий (лица людей и номерные знаки удалены). Согласие на такое использование фиксируется при регистрации сотрудника (кнопка «Принимаю» в боте; версия согласия и момент нажатия сохраняются в базе данных).

05

Передача данных третьим лицам

Оператор не передаёт персональные данные третьим лицам, за исключением следующего случая: результаты проверки (фотографии с разметкой и итог «чисто/грязно») автоматически направляются представителю управляющей компании, к которой прикреплён сотрудник. Данная передача предусмотрена согласием, которое сотрудник даёт при регистрации в боте.
