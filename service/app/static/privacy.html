Политика конфиденциальности

Настоящая Политика конфиденциальности описывает порядок обработки данных при использовании сервиса Rubbish Detector.

1. Назначение сервиса

Сервис предназначен для автоматического обнаружения объектов мусора на изображениях с использованием нейронной сети.

2. Какие данные обрабатываются

Пользователь может загрузить изображение для анализа. Загруженное изображение используется только для поиска объектов мусора и формирования результата.

3. Хранение изображений

Загруженные изображения не используются для постоянного хранения. Они могут временно сохраняться на сервере только на период обработки запроса.

4. Передача данных третьим лицам

Сервис не передает загруженные изображения и результаты обработки третьим лицам.

5. Ответственность пользователя

Пользователь самостоятельно несет ответственность за содержание загружаемых изображений. Не допускается загрузка материалов, нарушающих законодательство или права третьих лиц.

6. Безопасность

В сервисе применяются разумные технические меры защиты, однако абсолютная безопасность передачи данных через Интернет не может быть гарантирована.

7. Изменение политики

Политика конфиденциальности может быть изменена при развитии проекта.
